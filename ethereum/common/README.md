## Substreams Ethereum Foundational Modules

Common Ethereum substreams modules to extract events, calls, transactions with indexing

Use one of those optimized modules with a query string as a parameter:
* `filtered_events`
* `filtered_calls`
* `filtered_transactions`
* `filtered_events_and_calls`

The query string will be used for the block filter as well as the actual filtering of the events/calls/transactions.
